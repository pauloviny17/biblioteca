# BIBLIOTECA

Sistema de gerenciamento de uma biblioteca desenvolvido com php puro, MySQL, HTML, CSS e javascript.

O projeto permite cadastrar e gerenciar categorias, livros, consultar detalhes, alem de cadastro, login e gerenciamento do perfil de usuarios

## Requisitos

Para executar o projeto localmente, é necessario ter: 
* **XAMP**;
* **PHP 8 ou superior**;
* **MySQL 5.7 ou superior**;
* **apache**;
* **Navegador web atualizado**
